| 任务ID | 任务名称 | 优先级 | 预估工时 | 交付物 |
|--------|---------|--------|---------|--------|
| T2.8.1 | VAD 检测实现 | P0 | 4h | vad_detector.c |
| T2.8.2 | 音频流动态路由 | P0 | 6h | audio_router.c |
| T2.8.3 | AFE 独占 + RingBuffer 架构 | P0 | 6h | audio_afe.c |

> **RingBuffer 溢出策略**：AFE 生产者优先级 HIGH，TFLM 消费者 LOW。RingBuffer 满时**越过旧帧 (Overwrite Oldest)**，确保生产者永不阻塞。建议 RingBuffer 大小 16KB 而非 8KB，双倍缓冲空间。TFLM Arena (100KB) 分配在 PSRAM，RingBuffer 和 AFE 工作区分配在内部 RAM。

```
AFE 独占架构：
I2S DMA → AFE (唯一生产者，HIGH) → RingBuffer (16KB, 非阻塞写) → TFLM 消费者 (LOW)
                                                               → MultiNet 消费者 (LOW)
```

## 技术要点

```
┌─────────────────────────────────────────────────────────────┐
│                      ESP-SR 架构                             │

│                                                             │
│  ┌──────────┐    ┌──────────┐    ┌──────────┐             │
│  │ 麦克风    │───→│  AFE     │───→│ WakeNet  │ 唤醒检测    │
│  │ I2S      │    │ 音频前端  │    │ 唤醒词    │             │
│  └──────────┘    └──────────┘    └────┬─────┘             │
│                                        │                    │
│                                        ↓ 唤醒后             │
│                                   ┌──────────┐             │
│                                   │ MultiNet │ 命令识别    │

│                                        │                    │
│                                        ↓                    │
│                                   ┌──────────┐             │
│                                   │ 命令处理  │             │

│                                   └──────────┘             │
```

## 验收标准

| 检查项 | 验收标准 |
|--------|---------|
| 唤醒词识别率 | > 95%（安静环境） |
| 命令词识别率 | > 90%（安静环境） |
| 唤醒延迟 | < 500ms |
| 命令识别延迟 | < 300ms |
| 误唤醒率 | < 1 次/小时 |
| 内存占用 | < 600KB（语音模块） |

## 风险与缓解

| 风险 | 概率 | 影响 | 缓解措施 |
|------|------|------|---------|
| 唤醒词识别率低 | 中 | 高 | 优化 AFE 参数、增加训练数据 |
| 命令词混淆 | 中 | 中 | 增加命令词区分度 |
| 内存不足 | 中 | 高 | 使用 PSRAM、分步加载 |
| 噪声环境性能下降 | 高 | 中 | 优化 NS 参数、增加 VAD |
| **AEC 配置失败导致回声循环** | 高 | 高 | 严格按 ESP-ADF 示例配置 Reference 信号 |
| **DAC 与麦克风 I2S 时钟冲突** | 中 | 高 | 使用独立 I2S 通道（I2S0/I2S1） |
| **麦克风流资源抢占** | 高 | 高 | VAD 动态路由：无人声→TFLM，有人声→ESP-SR |
