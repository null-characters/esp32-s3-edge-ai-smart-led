### 情感光效映射表

| 情感标签 | 颜色 | 动画类型 | 触发场景 |
|---------|------|---------|---------|
| `happy` | 青色 | 呼吸 (2s周期) | 用户请求成功执行 |
| `thinking` | 橙色 | 流水 (左右移动) | LLM 正在处理 |
| `neutral` | 白色 | 常亮 | 待机状态 |
| `apologetic` | 黄色 | 慢闪 | 执行失败/无法理解 |
| `excited` | 彩色 | 律动 (快节奏) | 主动问候/欢迎 |

### RingBuffer 抗抖动设计

```c
// PSRAM RingBuffer 配置
#define AUDIO_RING_BUFFER_SIZE  (16000 * 2 * 1)  // 16kHz, 16-bit, mono, 1秒缓冲

typedef struct {
    uint8_t *buffer;           // PSRAM 分配
    size_t capacity;           // 总容量
    size_t write_pos;          // 写入位置
    size_t read_pos;           // 读取位置
    size_t available;          // 可读数据量
    SemaphoreHandle_t mutex;   // 线程安全
} audio_ring_buffer_t;

// 抗抖动阈值
#define JITTER_THRESHOLD_MS    500  // 缓冲不足500ms时暂停发送
```

## 验收标准

| 棡查项 | 验收标准 |
|--------|---------|
| WakeNet 保留 | 唤醒词识别率 > 95% |
| MultiNet 移除 | 编译无 MultiNet 相关代码 |
| WebSocket 连接 | 唤醒后 3s 内建立连接 |
| 音频上行 | 20ms/帧，无丢帧 |
| TTS 下行 | 播放流畅，无断续 |
| JSON 解析 | 正确执行 Action |
| 情感光效 | 动画效果符合设计 |
| MQTT 上报 | 状态同步正常 |

## 风险与缓解

| 风险 | 概率 | 影响 | 缓解措施 |
|------|------|------|---------|
| PSRAM 内存不足 | 中 | 高 | 优化缓冲区大小 |
| WebSocket 断连 | 高 | 高 | 自动重连 + 状态恢复 |
| JSON 格式错误 | 中 | 高 | Schema 校验 + 默认值 |
| 动画卡顿 | 中 | 中 | 独立动画任务 |
