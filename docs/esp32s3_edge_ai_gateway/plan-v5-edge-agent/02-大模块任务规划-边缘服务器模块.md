## 技术要点

### 边缘服务器架构

```
┌─────────────────────────────────────────────────────────────┐
│                    X99 Edge Server                          │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  ┌──────────────────────────────────────────────────────────┐ │
│  │                 Agent Backend (FastAPI)                    │ │
│  │  ┌──────────┐  ┌──────────┐  ┌──────────┐  ┌──────────┐ │ │
│  │  │WebSocket │→ │  STT     │→ │  LLM     │→ │  TTS     │ │ │
│  │  │音频流服务 │  │ Whisper  │  │ Ollama   │  │ Piper    │ │ │
│  │  │ :8080    │  │ :8001    │  │ :11434   │  │ :8002    │ │ │
│  │  └──────────┘  └──────────┘  └──────────┘  └──────────┘ │ │
│  │       ↑           ↑              ↑           ↓           │ │
│  │  PCM→Opus编码  Opus解码    Prompt+会话    音频输出      │ │
│  └──────────────────────────────────────────────────────────┘ │
│                                                                │
│  ┌────────────────┐  ┌────────────────┐  ┌────────────────┐   │
│  │ MQTT Broker    │  │ Conversation   │  │ Docker         │   │
│  │ (Mosquitto)    │  │ Manager        │  │ Compose        │   │
│  │ :1883          │  │ 会话历史维持    │  │ +自愈监控      │   │
│  └────────────────┘  └────────────────┘  └────────────────┘   │
│                                                                │
└────────────────────────────────────────────────────────────────┘
```

### 运维监控

| 检查项 | 工具 | 配置 |
|--------|------|------|
| 服务自愈 | Docker restart: unless-stopped | 所有服务崩溃后自动重启 |
| 健康检查 | Docker healthcheck (agent) | 30s 间隔，3 次失败标记异常 |
| 系统资源 | Prometheus + Node Exporter | CPU/内存/磁盘/GPU 温度监控 |
| 日志轮转 | Docker log rotate | 单容器日志上限 10MB，保留 3 份 |
| GPU 温度 | nvidia-smi + cron | 超过 85°C 触发风冷策略 |

### Docker Compose 服务清单

```yaml
services:
  ollama:
    image: ollama/ollama
    ports: ["11434:11434"]
    volumes: ["ollama_data:/root/.ollama"]
    restart: unless-stopped
    
  whisper:
    image: faster-whisper-server
    ports: ["8001:8001"]
    restart: unless-stopped
    
  piper:
    image: piper-tts-server
    ports: ["8002:8002"]
    restart: unless-stopped
    
  agent:
    build: ./agent_backend
    ports: ["8080:8080"]         # WebSocket 音频流 + REST API
    depends_on: [ollama, whisper, piper]
    restart: unless-stopped      # 自愈：崩溃后自动重启
    healthcheck:
      test: ["CMD", "curl", "-f", "http://localhost:8080/health"]
      interval: 30s
      timeout: 10s
      retries: 3
    
  mosquitto:
    image: eclipse-mosquitto
    ports: ["1883:1883", "9001:9001"]
    restart: unless-stopped

  prometheus:
    image: prom/prometheus
    ports: ["9090:9090"]
    volumes: ["./prometheus.yml:/etc/prometheus/prometheus.yml"]
    restart: unless-stopped

  node_exporter:
    image: prom/node-exporter
    ports: ["9100:9100"]
    restart: unless-stopped
```
