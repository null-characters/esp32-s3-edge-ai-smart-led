## 技术要点

### 边缘服务器架构

```
┌─────────────────────────────────────────────────────────────┐
│                    X99 Edge Server                          │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  ┌─────────────────────────────────────────────────────┐   │
│  │                  Agent Backend (FastAPI)             │   │
│  │  ┌─────────┐  ┌─────────┐  ┌─────────────────────┐  │   │
│  │  │  STT    │→ │  LLM    │→ │  TTS (Piper)        │  │   │
│  │  │ Whisper │  │ Ollama  │  │  中文语音           │  │   │
│  │  └─────────┘  └─────────┘  └─────────────────────┘  │   │
│  │       ↑           ↑              ↓                   │   │
│  │   音频输入    Prompt+记忆     音频输出              │   │
│  └─────────────────────────────────────────────────────┘   │
│                                                             │
│  ┌───────────────┐  ┌───────────────┐  ┌───────────────┐   │
│  │ MQTT Broker   │  │ WebSocket     │  │ Docker        │   │
│  │ (Mosquitto)   │  │ Server        │  │ Compose       │   │
│  └──────��────────┘  └───────────────┘  └───────────────┘   │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### Docker Compose 服务清单

```yaml
services:
  ollama:
    image: ollama/ollama
    ports: ["11434:11434"]
    volumes: ["ollama_data:/root/.ollama"]
    
  whisper:
    image: faster-whisper-server
    ports: ["8001:8001"]
    
  piper:
    image: piper-tts-server
    ports: ["8002:8002"]
    
  agent:
    build: ./agent_backend
    ports: ["8000:8000"]
    depends_on: [ollama, whisper, piper]
    
  mosquitto:
    image: eclipse-mosquitto
    ports: ["1883:1883", "9001:9001"]
    
  websocket:
    build: ./websocket_server
    ports: ["8080:8080"]
```

## 风险与缓解

| 风险 | 概率 | 影响 | 缓解措施 |
|------|------|------|---------|
| 硬件不兼容 | 中 | 高 | 采购前确认兼容性清单 |
| GPU 驱动问题 | 高 | 高 | 使用官方 CUDA 12.x |
| 模型下载慢 | 高 | 低 | 使用国内镜像源 |
| 性能不足 | 中 | 中 | 模型量化 (Q4_K_M) |
| Docker 网络问题 | 中 | 中 | 使用 host 网络模式 |
