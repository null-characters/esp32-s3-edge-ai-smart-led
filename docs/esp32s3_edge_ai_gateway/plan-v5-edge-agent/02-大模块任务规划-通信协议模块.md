## 技术要点

### MQTT Topic 结构

```
设备状态上报：
  node/{device_id}/radar/status     → 雷达状态 (presence, distance)
  node/{device_id}/sound/status     → 声音分类 (keyboard, speech, silence)
  node/{device_id}/light/status     → 灯光状态 (brightness, color_temp)
  node/{device_id}/system/heartbeat → 心跳 (uptime, memory)

指令下发：
  cmd/{device_id}/light/control     → 灯光控制 JSON
  cmd/{device_id}/audio/tts         → TTS 播放指令
  cmd/{device_id}/system/config     → 系统配置

唤醒选主：
  election/{room_id}/wakeup         → 唤醒选主请求
  election/{room_id}/vote           → 音频能量投票
```

### WebSocket 音频帧结构

```
┌────────────────────────────────────────────────────────────┐
│                    WebSocket 音频帧                         │
├────────────────────────────────────────────────────────────┤
│                                                            │
│  Header (4 bytes):                                         │
│  ┌────────┬────────┬────────┬────────┐                    │
│  │ Type   │ Seq    │ Length │ Flags  │                    │
│  │ 1byte  │ 1byte  │ 2bytes │ 1byte  │                    │
│  └────────┴────────┴────────┴────────┘                    │
│                                                            │
│  Payload:                                                  │
│  ┌─────────────────────────────────────┐                  │
│  │ PCM 音频数据 (16kHz, 16-bit, mono)  │                  │
│  │ 建议每帧 320 samples (20ms)         │                  │
│  └─────────────────────────────────────┘                  │
│                                                            │
│  Type 枚举:                                                │
│  0x01 = AUDIO_UPSTREAM   (ESP32 → Server)                 │
│  0x02 = AUDIO_DOWNSTREAM (Server → ESP32, TTS)            │
│  0x03 = CONTROL_CMD      (JSON 控制指令)                   │
│  0x04 = HEARTBEAT        (连接保活)                        │
│                                                            │
└────────────────────────────────────────────────────────────┘
```

### Function Calling JSON Schema

```json
{
  "$schema": "http://json-schema.org/draft-07/schema#",
  "title": "AgentCommand",
  "type": "object",
  "required": ["text", "emotion", "actions"],
  "properties": {
    "text": {
      "type": "string",
      "description": "TTS 播放文本"
    },
    "emotion": {
      "type": "string",
      "enum": ["happy", "thinking", "neutral", "apologetic", "excited"],
      "description": "情感标签，驱动光效"
    },
    "actions": {
      "type": "array",
      "items": {
        "type": "object",
        "required": ["type"],
        "properties": {
          "type": {
            "type": "string",
            "enum": ["set_brightness", "set_color_temp", "set_scene", "turn_off"]
          },
          "value": { "type": "integer" }
        }
      }
    },
    "context": {
      "type": "object",
      "properties": {
        "radar_state": { "type": "string" },
        "sound_state": { "type": "string" }
      }
    }
  }
}
```

## 验收标准

| 检查项 | 验收标准 |
|--------|---------|
| MQTT 连接 | ESP32 连接 Broker 成功 |
| Topic 通信 | 状态上报/指令下发正常 |
| WebSocket 连接 | 双向音频流建立成功 |
| 抗抖动 | RingBuffer 缓冲 500ms 无断续 |
| JSON 解析 | ESP32 正确解析 Function Calling JSON |
| Schema 校验 | 格式错误自动重试 |

## 风险与缓解

| 风险 | 概率 | 影响 | 缓解措施 |
|------|------|------|---------|
| Wi-Fi 断连 | 高 | 高 | 心跳检测 + 自动重连 |
| WebSocket 超时 | 中 | 中 | 30s 心跳保活 |
| JSON 解析失败 | 中 | 高 | Schema 校验 + 重试 |
| RingBuffer 溢出 | 中 | 中 | PSRAM 大缓冲 |
