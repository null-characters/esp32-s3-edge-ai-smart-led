## 开发流程

```
阶段一：边缘认知基建 (2周)
    硬件组装 → 系统部署 → LLM/STT/TTS → Agent Backend
              ↓
阶段二：通信协议 (1周)
    MQTT Broker → WebSocket 音频流 → JSON 协议
              ↓
阶段三：固件重构 (2周)
    ESP-SR 重构 → WebSocket 客户端 → JSON 处理 → 情感光效
              ↓
阶段四：多模态融合 (1周)
    雷达触发对话 → 声音场景联动 → 多设备选主
              ↓
阶段五：集成测试 (1周)
    功能测试 → 性能测试 → 稳定性测试
```

## 核心技术决策

| 决策项 | 选择 | 理由 |
|--------|------|------|
| 边缘服务器 | X99 + Tesla P4 | 性价比高，¥2241.8 |
| LLM | Ollama + Qwen2.5-7B-GGUF | 本地推理，隐私优先 |
| STT | Faster-Whisper | 中文识别准确率高 |
| TTS | Piper | 轻量级，支持中文 |
| 音频通信 | WebSocket | 双向流，低延迟 |
| 状态同步 | MQTT | 轻量级，适合 IoT |
| 唤醒词 | WakeNet (保留) | ESP-SR 成熟方案 |
| 命令词 | MultiNet (废弃) | 边缘 LLM 替代 |

## 与 v4 的关系

| 维度 | v4 云端智能体 | v5 边缘智能体 |
|------|-------------|-------------|
| 部署位置 | 云端 API | 局域网边缘服务器 |
| LLM | 云端调用 (GPT/Claude) | Ollama 本地 (Qwen2.5-7B) |
| 延迟 | 依赖网络质量 | < 1.5s TTFT |
| 隐私 | 数据上传云端 | 本地处理 |
| 成本 | API 调用费用 | 硬件一次性投入 |
| 可用性 | 依赖网络 | 离线可用 |

**决策**：v4 暂停，优先开发 v5 边缘智能体。待 v5 验证后再评估是否需要云端智能体。
