## v5.1 架构修正清单

| 修正项 | 说明 |
|--------|------|
| **WebSocket 合并** | 移除独立 websocket_server 服务，由 Agent Backend (FastAPI) 直接承载 |
| **P4 供电修正** | Tesla P4 为 PCIe 插槽供电（75W），无外接电源，无需供电线 |
| **Opus 编解码** | 新增 WebSocket 帧 Opus Codec 字段，带宽 256kbps→24kbps |
| **本地降级模式** | T3.1.5，WebSocket 断连时自动激活 5 条硬编码命令 |
| **会话管理** | T1.5.4，ConversationManager 维持多轮对话历史 |
| **音频优先级管理** | T3.2.6，Mic > 提示音 > TTS，检测到用户说话时静音 TTS |
| **运维监控** | T1.2.5，Docker 自愈 + Prometheus + 日志轮转 |
| **RingBuffer 移入 Phase 3** | 固件组件，从通信协议模块移至固件重构模块 |

## 开发流程

```
阶段一：边缘认知基建 (2周)
    硬件组装 → 系统部署 → LLM/STT/TTS → Agent Backend（含WS/会话管理）
              ↓
阶段二：通信协议 (1周) ← 可与阶段一并行（协议设计部分）
    MQTT Broker → WebSocket 音频流（含Opus）→ JSON 协议
              ↓
阶段三：固件重构 (3周)
    ESP-SR重构 → WebSocket+Opus+RingBuffer → JSON处理 → 降级 → 光效
              ↓
阶段四：多模态融合 (1周)
    雷达触发对话 → 声音场景联动 → 多设备选主
              ↓
阶段五：集成测试 (1周)
    功能测试 → 性能测试 → 稳定性测试
```

## 核心技术决策

| 决策项 | v5.0 | v5.1（修正后） |
|--------|------|----------------|
| WebSocket 服务 | 独立进程 `websocket_server` | Agent Backend (FastAPI) 直接承载，端口 :8080 |
| 音频传输 | PCM 原始 256kbps | PCM + Opus 编码，降至 24kbps |
| 服务器依赖 | 不可用 = 设备失智 | 本地降级模式，断连自动激活硬编码命令 |
| 对话状态 | Stateless，无上下文 | Session Manager，维持 N 轮 Chat History |
| TTS 打断 | 未定义 | 音频优先级管理，Mic > 提示音 > TTS |
| 运维 | 无 | Docker 自愈 + Prometheus 监控 |
| 总量 | 77 任务，199h | 82 任务，330h+（含工时修正） |
