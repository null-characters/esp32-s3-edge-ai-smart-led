# ESP32-S3 N16R8 v3 硬件连接框图

> 基于 ESP32-S3-NxRx 开发板（兼容 ESP32-S3-WROOM-1 模组）的智能照明网关硬件配置

## 一、开发板规格

| 特性 | 规格 |
|------|------|
| 型号 | ESP32-S3-NxRx 开发板 (兼容 ESP32-S3-WROOM-1) |
| 模组 | ESP32-S3-WROOM-1-N16R8 |
| 内核 | Xtensa LX7 双核，最高 240MHz |
| 内部 SRAM | 512KB |
| 外部 Flash | 16MB (Quad SPI) |
| 外部 PSRAM | 8MB (Octal SPI) |
| Wi-Fi | 802.11 b/g/n，2.4GHz |
| 蓝牙 | BLE 5.0 |
| GPIO | GPIO0-GPIO47 (共48个) |
| 板载RGB | WS2812 (GPIO48/特殊引脚) |
| 天线 | PCB天线 + 外接天线座 (IPEX/U.FL) |

### 开发板接口布局

| 接口 | 说明 |
|------|------|
| **Type-C (COM)** | 串口通信/调试接口，连接至 USB-UART 芯片 |
| **Type-C (USB)** | USB-OTG 接口，可直接与 ESP32-S3 通信 |
| **RST 按键** | 复位按键，按下后 MCU 复位 |
| **BOOT 按键** | 启动模式选择，按住复位进入下载模式 |
| **板载 RGB** | WS2812 LED，用于状态指示 |
| **天线座** | 外接天线接口，增强 Wi-Fi/BLE 信号 |

### 开发板特殊说明

- **5Vin引脚**：输入5V给开发板供电，**不是输出5V**
- **USB-OTG跳线**：短接背面焊盘后可对外部USB从设备供电
- **板载WS2812**：用于状态指示，与外部照明LED分开
- **Arduino IDE开发板选择**：ESP32S3 Dev Module
- **双 Type-C 接口**：COM 口用于调试下载，USB 口用于 USB-OTG 功能

## 三、GPIO 引脚分配表

| GPIO | 功能 | 方向 | 外设 | 说明 |
|------|------|------|------|------|
| **12** | I2S_WS | 输出 | INMP441 麦克风 | 字选择信号 |
| **13** | I2S_SD | 输入 | INMP441 麦克风 | 音频数据输入 |
| **14** | I2S_CLK | 输出 | INMP441 麦克风 | 位时钟信号 |
| **16** | I2S_BCLK | 输出 | MAX98357A DAC | 位时钟输出 |
| **17** | I2S_WS | 输出 | MAX98357A DAC | 字选择输出 |
| **18** | I2S_DIN | 输出 | MAX98357A DAC | 音频数据输出 |

### 3.2 电源板控制接口 (PWM + ADC)

| GPIO | 功能 | 类型 | 说明 |
|------|------|------|------|
| **4** | PWM_BOOST | PWM输出 | Boost升压PWM控制信号 (软件控制升压) |
| **5** | PWM_WARM | PWM输出 | 暖色温(W-) MOS管PWM控制 (2700K暖白光) |
| **6** | PWM_COLD | PWM输出 | 冷色温(C-) MOS管PWM控制 (6500K冷白光) |
| **7** | ADC_VFB | ADC输入 | Boost输出电压反馈检测 (GPIO7 = ADC1_CH6) |

### 3.3 板载状态指示

| GPIO | 功能 | 类型 | 说明 |
|------|------|------|------|
| **48** | WS2812_DATA | 单线协议 | 板载RGB LED状态指示 |

> ⚠️ **注意**：GPIO48 用于板载 WS2812 RGB LED（状态指示），与外部 LED PWM 照明控制分开。

### 3.4 雷达通信接口

| GPIO | 功能 | 方向 | 外设 | 说明 |
|------|------|------|------|------|
| **8** | UART_TX | 输出 | LD2410 雷达 | 数据发送 |
| **9** | UART_RX | 输入 | LD2410 雷达 | 数据接收 |

### 3.5 预留/未使用 GPIO

| GPIO 范围 | 状态 | 备注 |
|-----------|------|------|
| GPIO0-3 | 预留 | 启动引脚/Flash |
| GPIO10-11 | 可用 | 预留扩展 |
| GPIO15 | 可用 | 原RGB蓝色通道，现预留扩展 |
| GPIO19-21 | 可用 | 预留扩展 |
| GPIO35-48 | 可用 | 预留扩展 (GPIO48为板载WS2812) |

> ⚠️ **注意**：GPIO4-7已分配给电源板控制接口，不再可用。

| 色温控制 | GPIO5 (W-暖色温) + GPIO6 (C-冷色温)，3kHz PWM |
| MOS管驱动 | N沟道MOSFET，PWM占空比控制 |
| 输出接口 | V+ (24V)、W- (暖色温)、C- (冷色温)、5V、GND |

### 4.6 Boost升压控制参数

| 参数 | 规格 | 说明 |
|------|------|------|
| Boost PWM频率 | 50kHz | 固定频率，软件控制 |
| 色温 PWM频率 | 3kHz | 双路独立控制，避免频闪 |
| PWM占空比 | 0% - 95% | 控制升压比和亮度 |
| 目标电压 | 24V | LED灯带工作电压 |
| 电压采样精度 | ~6.2mV | ADC 12-bit分辨率 |
| 闭环控制 | PID算法 | 软件实现稳压控制 |

### 4.7 GPIO引脚验证

| GPIO | 功能 | 验证结果 | 说明 |
|------|------|----------|------|
| **GPIO4** | PWM_BOOST | ✅ 合适 | 支持LEDC输出，无启动约束 |
| **GPIO5** | PWM_WARM | ✅ 合适 | 支持LEDC输出，无启动约束 |
| **GPIO6** | PWM_COLD | ✅ 合适 | 支持LEDC输出，无启动约束 |
| **GPIO7** | ADC_VFB | ✅ 合适 | ADC1_CH6，启动时可安全读取 |

> ⚠️ **GPIO选择原则**：
> - GPIO0-3：启动引脚/Flash，不可使用
> - GPIO4-7：通用GPIO，支持PWM/ADC，无特殊约束
> - GPIO7作为ADC输入时，启动期间读取不会影响启动流程
> - 所有PWM引脚均使用LEDC外设，支持硬件PWM生成

### 电源板架构说明

电源板采用模块化设计，包含以下核心电路：

| 电路模块 | 输入 | 输出 | 控制方式 | 说明 |
|---------|------|------|----------|------|
| **AC-DC适配器** | 220V AC | 20V DC | - | 外置适配器或板载整流电路 |
| **LDO降压** | 20V DC | 5V DC | - | 为ESP32-S3开发板和外设供电 |
| **Boost升压** | 20V DC | 24V DC | PWM 50kHz软件控制 | 为LED灯带供电 |
| **MOS管驱动** | 24V DC | PWM调光 | PWM 3kHz占空比 | 双路色温独立控制 |

### 电源板接口定义

电源板对外接口：

| 接口 | 类型 | 说明 |
|------|------|------|
| **LN输入** | 市电输入 | 220V交流电输入端子 |
| **V+输出** | 24V正极 | LED灯带公共正极 |
| **W-输出** | 暖色温负极 | 暖白光(2700K)控制线，接MOS管 |
| **C-输出** | 冷色温负极 | 冷白光(6500K)控制线，接MOS管 |
| **5V输出** | 5V直流 | 为ESP32-S3开发板供电 |
| **GND** | 公共地 | 所有电路共地 |

### ESP32-S3与电源板连接

| ESP32-S3 GPIO | 电源板接口 | 功能说明 |
|---------------|-----------|----------|
| **GPIO4** | Boost PWM输入 | 软件控制Boost升压开关管 |
| **GPIO5** | W- MOS管驱动 | 暖色温PWM调光控制 |
| **GPIO6** | C- MOS管驱动 | 冷色温PWM调光控制 |
| **GPIO7** | Vfb电压反馈 | ADC检测Boost输出电压(分压后0-3.3V) |
| **5Vin** | 5V电源输入 | 从电源板LDO获取5V供电 |

### 电压反馈计算

Boost输出电压检测通过电阻分压实现：

```
24V ──┬── R1 (100kΩ) ──┬── GPIO7 (ADC)
      │                  │
     LED                R2 (10kΩ)
      │                  │
     GND ───────────────┴── GND

分压比: V_adc = V_boost × R2 / (R1 + R2)
      = 24V × 10kΩ / (100kΩ + 10kΩ)
      ≈ 2.18V (在ADC安全范围内)

最高可测电压: 3.3V × (R1+R2)/R2 = 3.3V × 11 = 36.3V

ADC分辨率: 12-bit (0-4095)
电压分辨率: 3.3V / 4095 ≈ 0.8mV
实际电压分辨率: 0.8mV × (R1+R2)/R2 ≈ 8.9mV
```

### Boost升压参数计算

从20V升压至24V的参数：

```
输入电压: Vin = 20V
输出电压: Vout = 24V
升压比: D = (Vout - Vin) / Vout = (24 - 20) / 24 ≈ 16.7%

最小占空比: ~17% (理论值)
实际占空比范围: 17% - 80% (留有余量应对负载变化)

Boost PWM频率: 50kHz
色温PWM频率: 3kHz (避免低频可见闪烁)
```
